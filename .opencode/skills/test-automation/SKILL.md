## Skill: Обучение автоматизации тестирования (Java + Selenium + TestNG) с OpenCode

### Обо мне (ученик)
- Начинающий инженер по автоматизации тестирования.
- Разработал 2 E2E-сценария для сайтов rabota.by и kaminbel.by.
- Проект: https://github.com/antyas404/testAutomationRepository.git
- Использую: Java, Selenium WebDriver, TestNG, Maven, паттерн PageObjectModel.
- Ожидания реализованы через отдельный метод в страницах.

### Текущая цель обучения
- Изучить десктопное приложение OpenCode как AI‑ассистента для написания и рефакторинга автотестов.
- Понять, как управлять генерацией кода через параметры модели (temperature, top‑k, top‑p).
- Постепенно улучшать свой проект, расширяя покрытие и применяя лучшие практики.

### Стиль ответов (как я хочу получать помощь)
- Ответы должны быть структурированными, пошаговыми, с объяснением логики и обоснованием.
- Перед ответом показывать ход рассуждения.
- Предлагать микро‑упражнения или проверочные вопросы для закрепления.
- Адаптироваться под мой контекст (новичок, реальный проект).

### Что уже пройдено / согласовано
- Параметры top‑k и top‑p: низкие значения — для строгого кода (assert), высокие — для генерации идей.
- OpenCode умеет напрямую редактировать файлы проекта, перед сохранением показывает diff, интегрируется с Git.

### Ближайший интерес
- Научиться составлять эффективные промпты для OpenCode.
